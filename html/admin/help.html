Quick Start Guide

With this plugin you can price the files and the groups to sell them, and receive the payments to your PayPal or Stripe account automatically, or you can make a subscription system to offer your files for a limited time only.

You need only a PayPal Business account, or a Stripe account, or both.

  • For PayPal, create a REST API app and copy its Client ID and its Secret. Every app has two pairs of them, one for the sandbox and one for the live payments.
  • For Stripe, copy the Secret key from the API keys page. A key that starts with sk_test_ is for testing, and the one that starts with sk_live_ takes real payments.

For developers : you can test everything without real money, with the sandbox of PayPal and the test key of Stripe.

Set the keys in {olang.CONFIG_KLJ_MENUS_KLEEJA_PAYMENT}, and turn the payment methods on or off in {olang.CONFIG_KLJ_MENUS_KJ_PAY_ACTIVE_MTHD}. A method is offered to the buyers only when it is on and its keys are set.

The Currency Code has to be 3 letters only, like USD , EUR , CHF , and the payment method has to support it. Check the currencies of PayPal and of Stripe.

Live Mode : it is about PayPal, when it is off the Client ID and the Secret of the sandbox are used. Stripe follows the key that you set.

Min Withdrawal Limit (Groups Data) : it's the minimal amount that a user of the group can request for withdrawing, if it's 0 that means the user can request any amount he wants.

Download Link Expire After x Days, 0 is available forever :
after the user makes a payment, he will receive an e-mail with the download link, and he can not download the bought file without the cookie of the browser that he paid with, so this sets the number of the days that he can access the file.
note : the members of the groups that can access the purchases page keep their files, the days do not count for them.

Percentage of owner's earnings : if a user uploads a file and sells it, he receives this percentage from the file price with every payment.
note : he receives it only if his group has the "Receive Profits" permission.

Min/Max Price Limit :
the users of the groups that have the "Receive Profits" permission can set the price of their files, and these two options are the limits of the price that they can set.
note : these options are for the users area only, not for this control panel.

The buyer chooses a payment method and goes to the page of PayPal or Stripe, the card and the account details are typed there only, they never pass through your website.

  • PayPal : the buyer approves the payment on PayPal, and the money is taken when he comes back to your website. If he does not come back, nothing is taken from him.
  • Stripe : the buyer pays with his card on the payment page of Stripe, and when he comes back your website asks Stripe if the payment is paid.
  • Balance : the members who receive profits can pay with their balance.

A payment stays in the pending payments until its buyer comes back. If a buyer says that he paid and the payment is still pending, check it in your PayPal or Stripe account.

To price a file go to {olang.KJP_PRC_FILE}, with the file id or the file link you can open the file details, and under them there is a form to set the price. If the file was paid, you can change the price or set it to 0 to make the file free again.

To set a price for a group go to the groups page, open Edit Data of the group, and you will find the Join price.

Note : the default groups and the default registration group can not be paid.

The file owner and the website founders can download the file for free, and if the subscriptions are active, then any member who has a valid subscription can access all the files, and the owners of the paid files get points. The founder role is not the admins group, the founders can give the founder role to any member even if he is not in the admins group.

The first page has the numbers and the amounts of the approved payments.

  • all transactions : all the approved payments since you started using this plugin.
  • monthly transactions : the payments of this month, it starts again every month.
  • daily transactions : the payments of today only.

You can see the payments and the amounts of any day or month in the archives. For a monthly archive keep the day empty and select the month and the year.

Only the website founders can access this control panel.

Note : the amount of PayPal is the net profit, without its fees. The amounts of the other methods are written with the fees.

The links of the files and the images have to be made with the id of the database row, a direct link opens the file without a payment. Check Here

When you give the "Receive Profits" permission to a group, its users get the "Payments Control" page, they can price their files in the limits that you set, they receive the percentage of the file price, and they can ask to withdraw their balance to their PayPal account.

When a user requests to withdraw an amount, you will see it in the requests list of the payouts.
If you cancel the payout, the amount goes back to the user balance.
If you send it, the amount is sent with PayPal to the e-mail address that the user has in your website, and the payout state becomes 'Sent'. When you view a payout with this state you can check it, to know if it is received.
If PayPal could not deliver it, the check cancels the payout and the amount goes back to the user balance.

Note : the payouts have to be enabled for your PayPal account, you can ask PayPal for them from your account. If the e-mail address of the user has no PayPal account, the money comes back to your account after 30 days.

With the subscriptions you offer all the files for a limited time, and the user needs to renew his subscription if he wants to access the files again.

Note : you can use this plugin with selling files, with the subscriptions, or with both.
